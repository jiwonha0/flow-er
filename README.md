# 페이스메이커 MVP

외출 준비 시간을 역산하고, 단계별 실제 완료 시간을 기록하는 React Native + Expo 앱입니다.

## 현재 구현

- 약속 시각, 이동시간, 안전 버퍼를 기반으로 집 출발 시각을 역산
- 아침 식사 → 샤워·씻기 → 화장·옷 입기 → 짐 챙기기 준비 루틴 생성
- 현재 단계 시작, 완료, 5분 연장
- 초록·노랑·빨강 페이스 상태
- 단계별 실제 완료 시간 기록 및 다음 계획에 반영하는 개인화 로직

## 다음 구현 순서

1. `expo-notifications`로 단계별 로컬 알림 예약
2. Google OAuth와 Calendar API로 일정 선택
3. ODsay API(대중교통), NAVER Directions API(자차)를 서버리스 함수에서 호출
4. Supabase에 사용자 설정과 완료 기록을 저장

## 실행

의존성을 설치한 뒤 아래 명령으로 실행합니다.

```bash
npm install
npm run start
```

개발 초기에는 실제 기기에서 Expo Go로 화면과 로컬 타이머를 확인할 수 있습니다. Google 로그인과 푸시 알림을 붙일 때는 개발 빌드로 전환합니다.
